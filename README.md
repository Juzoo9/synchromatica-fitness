# Synchromatica — Fitness Mini App

Однофайловый Telegram Mini App для отслеживания прогресса в зале.

- Один `index.html`, без зависимостей и сборки.
- Прогрессия нагрузок: сравнение с прошлой тренировкой + подсказка «что пробивать».
- Таймер отдыха между подходами с тактильной отдачей (Telegram HapticFeedback).
- Хранение: Telegram CloudStorage, с fallback на localStorage.
- Работает и внутри Telegram, и в обычном браузере.

Открывается как WebApp внутри Telegram-бота.
