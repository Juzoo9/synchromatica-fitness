# Synchromatica — Fitness Mini App

Однофайловый Telegram Mini App для отслеживания прогресса тренировок в зале.

## 🔗 Прямая ссылка (GitHub Pages)
👉 **https://juzoo9.github.io/synchromatica-fitness/**

## ✨ Возможности
- **Работает 24/7 без бэкенда и без компьютера**: статический хостинг на GitHub Pages + хранилище Telegram CloudStorage.
- **Расписание тренировок**: готовые сплиты на **Понедельник**, **Среду**, **Пятницу** с автовыбором дня недели.
- **Полная кастомизация**: добавление своих дней/тренировок, изменение упражнений, добавление упражнений прямо во время тренировки.
- **Хранение по ключам (Keyed Storage)**: каждая тренировка сохраняется отдельным ключом (`w_<id>`), что решает проблему лимитов и позволяет хранить историю годами.
- **Статистика и графики прогресса**: интерактивный график роста рабочих весов (PR), тоннаж и аналитика за 4 недели.
- **Таймер отдыха**: интервалы 1:00, 1:30, 2:00, 3:00 с виброоткликом (Telegram HapticFeedback).

## 🤖 Как привязать к боту в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/mybots` и выберите вашего бота.
3. Перейдите в **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Укажите ссылку: `https://juzoo9.github.io/synchromatica-fitness/` и название кнопки (например, `🏋️ Зал`).
