## ⚡ О проекте

**Synchromatica Fitness** — эталонный автономный трекер тренировок с алгоритмами прогрессии нагрузок (NSCA), сквозным клиентским шифрованием и выгрузкой отчётов в электронные таблицы.

Проект спроектирован как высокоэффективный **коммерческий шаблон Zero-Backend Telegram Mini App**:
- **0₽ расходов на сервера и базы данных**: приложение функционирует 24/7 на бесплатном статическом хостинге (GitHub Pages / Cloudflare Pages) и сохраняет данные в персональное зашифрованное хранилище `Telegram CloudStorage`.
- **Раздельная адаптация Web и TG**: эргономичный мобильный интерфейс для Telegram с тактильными виброоткликами (Haptic Feedback) и просторный двухколоночный дашборд (1020px) для десктопных браузеров.
- **Выгрузка в Excel / Google Таблицы (CSV)**: полный экспорт тренировочных сессий с поддержкой UTF-8 BOM, разделителем `;` и детализацией по каждому подходу.
- **Встроенная защита интеллектуальной собственности**: блокировка контекстного меню, хоткеев DevTools (`F12`, `Ctrl+Shift+I/J/C`, `Ctrl+U`, `Ctrl+S`) и криптографическая подпись-водяной знак.
- Разработано в студии автоматизации и разработки **[Synchromatica AI](https://t.me/synchromatica)**.

## 🚀 Что под капотом у трекера

### 1. 🔒 Сквозное шифрование и защита данных (Privacy-First)
* **Односторонний хэш SHA-256 с солью**: реальный Telegram ID никогда не фигурирует в открытом виде в URL или ключах хранилища. Восстановить реальный аккаунт математически невозможно.
* **Шифрование AES-GCM 256-bit**: все тренировочные программы, подходы, рабочие веса и заметки шифруются локально на клиенте перед отправкой в Telegram CloudStorage.
* **Защита от инспекции и копирования**: блокировка DevTools, контекстного меню и горячих клавиш исходного кода. Водяной знак: `SHA256:53796e6368726f6d61746963612d41492d32303236`.

### 2. 📊 Экспорт данных в Excel / Google Таблицы (CSV)
* Выгрузка полной истории тренировок одним кликом.
* Корректная кодировка UTF-8 BOM (`\uFEFF`) — русские символы открываются в Excel без кракозябр.
* Формат с разделителем `;` (европейский/российский стандарт Excel).
* Детальный отчёт: дата, время, программа, упражнение, номер подхода, вес, повторения, тоннаж подхода и длительность.

### 3. 🧠 Спортивная прогрессия весов (NSCA 2-for-2 Rule & Double Progression)
* Алгоритм анализирует подходы: если вы выполняете целевой вес 2 тренировки подряд на 10+ повторений — система рекомендует прибавить `+2.5 кг` (верх тела) или `+5 кг` (ноги).
* Детектор плато предупреждает о застое веса при 3+ сессиях подряд без роста.

### 4. 🎨 Премиальный пастельно-зелёный дизайн (Sage & Emerald)
* Спокойные, благородные пастельные тона (`#52c788`, `#11241a`, `#08120c`).
* Двухколоночный адаптивный дашборд для ПК и эргономичный мобильный вид для смартфонов.

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Введите команду `/mybots` и выберите вашего бота.
3. Перейдите: **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Укажите ссылку:
   ```text
   https://juzoo9.github.io/synchromatica-fitness/
   ```
5. Введите название кнопки (например, `🏋️ Трекер`).
